# Outputs for the selected scope
Apply runtime.md and period-scope.md. The core deliverables are a traceable ledger and evidence-backed insights, not a particular file type or website.

## Review surface
Use chat, copyable tables, supported files, or an approved private page. Show source coverage, duplicate candidates, material classification questions, receipts/refunds, and optional financial-profile changes. Use stable IDs, exact unresolved counts, source evidence, suggested answers, and a clear reply format. Update the ledger after answers and show only remaining questions.

## Ledger
Prefer Excel when supported. Otherwise export CSV tables or provide copyable tables in numbered batches, with expected row counts. Never hide truncated rows or imply an exported file exists when it does not.

Include:
- Scope, requested dates/event, actual coverage, gaps, currency and accounting basis.
- Gross expenses, receipts/refunds and net spending; income separately.
- Category summary and a budget comparison only with a confirmed matching budget.
- Appropriate time/event breakdown, not necessarily monthly.
- Included rows, excluded/duplicate audit, full normalized records, confirmed decisions and source reconciliation.

If an XLSX workbook is supported use readable widths, typed dates/currency, filters and formula-driven summaries. Reopen and check formulas; render when available, otherwise disclose lack of visual verification. For CSV guard spreadsheet formula injection in untrusted text fields, preserve numeric amount columns and disclose export escaping.

Only add assets, goals, net-worth bridges and metric history when dated inputs support them. Missing balances remain missing.

## Insights
Title the report 账单洞察 plus the interval/event. Deliver Markdown/text by default, local HTML when supported, or an approved private website when available.

Show:
- Coverage and separate bookkeeping/financial-review completion states.
- Net spending, gross-versus-refund reconciliation, categories, and largest supported drivers.
- Event costs versus recurring commitments; hard commitments separate from adjustable spending.
- Two to four concise quantified insights and at most three actions with timing and evidence.
- Assumptions, gaps, unknowns and links/row IDs to supporting records.
- Comparable history only when scope and coverage permit it.

Monthly means/trends are conditional under period-scope.md. Do not annualize a trip or treat missing dates as zero. No budget means no over-budget claim. No current financial snapshot means no precise current safety metrics.

## Final status and continuation
Use dated names with years, e.g. 记账_2026-08-17_2026-09-05_最终版.xlsx. If coverage is incomplete, prominently label 已提供资料范围内 and list gaps even when decisions on those records are resolved. Unresolved decisions require 阶段性处理（含未决）, not 最终版.

Return ledger plus report in the actual supported formats, and a saved or copyable continuation record: scope, coverage, processed batches, confirmed rules, decisions, pending IDs and artifact names. Keep private state outside this repository. If files cannot be saved, let the user copy/download and re-upload next time. Do not require hosting or long-term platform memory.

## Verification
Reconcile all row counts, exclusions, refunds and totals; check date bounds, cross-period links, currencies and unknowns. Verify formulas with an actual calculation tool. For multi-currency data separate totals unless conversion rates/dates are documented. Verify report values against the ledger. Online publishing checks apply only if publishing was selected and supported.
