# {{PERIOD}} 在线待确认页内容契约

过程确认默认发布到私有 Sites 项目，不把此模板直接作为纯文本清单或本地 HTML 文件交付。

页面顶部必须明确显示：

- 当前检查点名称
- 剩余待确认数量
- 用户只需要完成的具体动作
- 完成后的回复方式

每笔使用稳定编号，并显示：

```text
Q01
日期｜来源｜商户｜金额
原始说明：
为什么需要确认：
系统建议：
你的分类/说明：
```

可用处理方式：

- 分类改为：`分类名`
- AA 还款，冲抵：`分类名`
- 退款，冲抵：`分类名`
- 真实收入，不纳入
- 工资 / 理财 / 内部转账，不纳入
- 押金支出 / 退回，不纳入日常账单
- 一次性支出，分类为：`名称`
- 保持其他buffer

页面应在用户填写时尽量将草稿保存在当前设备，并提供“复制答案”操作。设备草稿不是账本的正式决定；用户把答案返回对话后才写回账本。复制内容使用以下格式：

```text
Q01：三餐；聚餐
Q02：退款，冲抵衣服鞋子；退鞋
```

收到回复后，将决定写回账本，重新生成页面并向同一私有站点部署新版本，只保留仍未解决的问题。剩余数量为零时，显示“复核已完成”，不渲染空的待确认表格。
